# Unseen-product recommendations

## Context & methods
Cosine similarity on binary customer-product histories, compared with popularity. Evaluate on the next 28 days.

### Key assumptions
Only returning customers with an unseen purchase inside the preselected top-1,500 catalogue are evaluated. Repeat purchases are excluded. This does not measure conversion uplift or all-customer performance.

## Takeaways
A similarity model must be compared with popularity before adding complexity. These scores cover a restricted cohort; adding all-customer and repeat-purchase evaluation could change the conclusion. The dashboard shows 200 customer aliases for inspection, while evaluation uses the full eligible cohort.
